# 🌍 ExploreWorld Tours – Travel Agency Website

ExploreWorld Tours is a travel agency website developed using **ASP.NET Web Forms and C#**. The website helps users explore travel destinations, view tour packages and make travel bookings through a simple and user-friendly interface.

## ✨ Features

- **Home Page:** Introduction to ExploreWorld Tours.
- **Destination Page:** Explore different travel destinations.
- **Packages Page:** View available travel packages.
- **Booking Page:** Select a destination and enter booking details.
- **Price Calculation:** Calculate booking costs based on the selected destination and number of travellers.
- **Booking Confirmation:** Display booking details after successful validation.
- **Payment Demo:** Display a demonstration UPI QR code for payment instructions.

## 🛠️ Technologies Used

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open `WebApplication20.slnx` in Visual Studio 2022.
3. Wait for the project to load.
4. Build the solution.
5. Run the project using IIS Express.
6. Explore the website through your browser.

## 🎯 Project Objective

The main objective of ExploreWorld Tours is to develop a user-friendly online travel agency website where users can explore destinations, view travel packages and make bookings conveniently.
